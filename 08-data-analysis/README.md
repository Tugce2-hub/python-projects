# CSV Sales Data Analysis

A beginner-level data analysis project developed using Python, Pandas, and Matplotlib.

## Project Overview

This project analyzes a sample sales dataset to explore product performance, calculate revenue, and compare sales across different product categories.

## Dataset

The dataset contains 8 products from 3 categories:

- Electronics
- Furniture
- Stationery

### Dataset Columns

| Column | Description |
|---|---|
| Product | Product name |
| Category | Product category |
| Quantity | Number of units sold |
| Unit_Price | Price per unit |

## Technologies

- Python 3
- Pandas
- Matplotlib
- Google Colab

## Analysis

- CSV file reading and data exploration
- Dataset summary statistics
- Revenue calculation
- Category-based sales analysis
- Bar chart visualization

## Project Structure

- `sample_sales.csv` – Sample sales dataset
- `sales_analysis.py` – Revenue calculations
- `data_exploration.py` – Dataset exploration
- `category_analysis.py` – Category-based analysis
- `sales_visualization.py` – Sales visualization
