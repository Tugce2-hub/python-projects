
# Customer Sales Analysis (SQL)

## Project Overview

This project analyzes customer and sales data using SQL and SQLite. It explores customer purchasing behavior, product revenue, and order patterns through practical SQL queries.

## Dataset

The project uses two relational tables:

- **customers:** Customer ID, name, city, and age.
- **orders:** Order ID, customer ID, product, and order amount.

The project uses a small sample dataset created for SQL practice.

## Project Objectives

- Analyze customer purchasing behavior.
- Calculate total spending per customer.
- Identify revenue by product.
- Calculate average order value.
- Count orders per customer.
- Identify customers with and without orders.
- Practice extracting business insights from relational data.

## SQL Concepts

The project demonstrates:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions: SUM, AVG, COUNT
- INNER JOIN
- LEFT JOIN
- Primary Keys and Foreign Keys

## Key Analysis Queries

1. Display all customers and orders.
2. Analyze total spending by customer.
3. Calculate total revenue by product.
4. Calculate the average order amount.
5. Filter orders above a specified amount.
6. Count orders per customer.
7. Identify customers whose total spending exceeds 10,000.
8. Find customers with and without orders using LEFT JOIN.

## Key Findings

Based on the sample dataset:

- Total revenue: 65,200
- Total number of orders: 6
- Average order amount: 10,866.67
- Highest revenue product: Laptop
- Highest-spending customer: Ayse
- One customer has no orders.
